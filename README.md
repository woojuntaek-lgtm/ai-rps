# 나를 읽는 AI 가위바위보

내 지난 선택을 학습해 **다음 수를 예측하는 AI**와 가위바위보 30판 대결. 판이 거듭될수록 AI가 나를 "읽어 가는" 과정을 그래프로 보며, 머신러닝의 기본 원리(데이터 → 패턴 학습 → 예측)를 1분 만에 체험할 수 있습니다. 파일 하나(`index.html`)로 동작하며 인터넷·서버·로그인·광고가 없습니다.

> **바로 하기: https://woojuntaek-lgtm.github.io/ai-rps/**

## 특징
- AI 수준 3단계: 쉬움(직전 1수 기억), 보통(직전 2수·승패 습관), 어려움(여러 예측법을 동시에 돌려 최근 잘 맞힌 쪽을 믿는 앙상블)
- 공정한 대결: AI는 사용자가 고르기 **전에** 손을 정해 둠(🔒), 다음 판 예측은 가려 둠
- 판마다 AI의 판단 근거와 예측 확률, 결과 화면에서 AI 승률 변화 그래프·적중률·나의 습관 분석
- 마르코프 연쇄·앙상블·추천 시스템과의 연결을 쉬운 말로 설명
